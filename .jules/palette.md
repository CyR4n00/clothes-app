## 2026-07-24 - [AnimatedTabBar Accessibility]
**Learning:** [Custom navigation elements (like `AnimatedTabBar`) lack native defaults and require manual application of `accessibilityRole`, `accessibilityLabel`, and `accessibilityState` to support screen readers, especially icon-only buttons.]
**Action:** [Always ensure that custom UI implementations manually handle accessibility attributes according to localization requirements (e.g., Japanese labels for primary routes).]
