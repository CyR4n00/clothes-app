## 2024-07-01 - Add accessibility labels to icon-only buttons
**Learning:** For a localized app, adding accessibility labels requires translating roles and interactions to the app's primary language (e.g., Japanese for this project) to ensure screen readers provide culturally/linguistically appropriate guidance for icon-only interactive elements.
**Action:** When adding accessibility features like `accessibilityLabel`, always refer to existing localized copies to ensure correct translations instead of using generic English labels.
