## 2024-05-27 - 🛡️ Sentinel: [High] Secure Storage for Authentication Tokens
**Learning:** React Native's `AsyncStorage` is an unencrypted, plaintext key-value store. Storing sensitive authentication tokens (like Supabase session tokens) in it exposes them to local access vulnerabilities.
**Action:** Always use a secure storage solution, such as `expo-secure-store`, for sensitive data on native platforms. Since `expo-secure-store` doesn't support web, implement a platform-aware adapter that gracefully falls back to `AsyncStorage` when `Platform.OS === 'web'`.
## 2024-05-30 - Fix Floating Promises in Secure Storage Adapter
**Vulnerability:** The custom `ExpoSecureStoreAdapter` for Supabase authentication in `outfit-swiper/src/lib/supabase.ts` did not return the promises generated by `SecureStore.setItemAsync` and `SecureStore.deleteItemAsync`. This created floating promises.
**Learning:** Omitting the return statements causes the Supabase client to assume the storage action was instantaneously successful. It ignores any potential keystore failures (e.g., storage full, device lock issues), which can lead to insecure session states or silent token loss.
**Prevention:** Always explicitly `return` the promises generated by asynchronous storage wrapper functions like `setItem` and `removeItem` to ensure external clients can correctly await and handle potential failures.
