## 2024-05-27 - 🛡️ Sentinel: [High] Secure Storage for Authentication Tokens
**Learning:** React Native's `AsyncStorage` is an unencrypted, plaintext key-value store. Storing sensitive authentication tokens (like Supabase session tokens) in it exposes them to local access vulnerabilities.
**Action:** Always use a secure storage solution, such as `expo-secure-store`, for sensitive data on native platforms. Since `expo-secure-store` doesn't support web, implement a platform-aware adapter that gracefully falls back to `AsyncStorage` when `Platform.OS === 'web'`.
## 2024-07-17 - [Floating Promises in SecureStore]
**Vulnerability:** The custom Supabase storage adapter wrapping Expo's SecureStore was missing return statements for `setItem` and `removeItem` async methods.
**Learning:** In React Native with Supabase, failing to return promises from storage adapter methods causes the auth client to assume instantaneous success, masking Keystore/Keychain failures and leading to insecure session states or silent token loss.
**Prevention:** Always ensure custom storage adapters explicitly return the Promises generated by their underlying async operations.
