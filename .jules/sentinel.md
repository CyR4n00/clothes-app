## 2024-05-27 - 🛡️ Sentinel: [High] Secure Storage for Authentication Tokens
**Learning:** React Native's `AsyncStorage` is an unencrypted, plaintext key-value store. Storing sensitive authentication tokens (like Supabase session tokens) in it exposes them to local access vulnerabilities.
**Action:** Always use a secure storage solution, such as `expo-secure-store`, for sensitive data on native platforms. Since `expo-secure-store` doesn't support web, implement a platform-aware adapter that gracefully falls back to `AsyncStorage` when `Platform.OS === 'web'`.
## 2024-05-28 - 🛡️ Sentinel: [CRITICAL] Fix floating promises in secure storage adapter
**Vulnerability:** The SecureStore adapter for Supabase was silently discarding Promises returned by `setItemAsync` and `deleteItemAsync`.
**Learning:** React Native's Supabase auth flow relies on properly chaining Promises from the storage adapter. Omitting `return` creates floating promises, causing the client to assume instantaneous success and ignore potential keystore failures, leading to insecure session states.
**Prevention:** Always explicitly return Promises generated by async storage wrapper methods.
