## 2024-05-27 - 🛡️ Sentinel: [High] Secure Storage for Authentication Tokens
**Learning:** React Native's `AsyncStorage` is an unencrypted, plaintext key-value store. Storing sensitive authentication tokens (like Supabase session tokens) in it exposes them to local access vulnerabilities.
**Action:** Always use a secure storage solution, such as `expo-secure-store`, for sensitive data on native platforms. Since `expo-secure-store` doesn't support web, implement a platform-aware adapter that gracefully falls back to `AsyncStorage` when `Platform.OS === 'web'`.
## 2026-07-18 - [Floating Promises in Auth Storage]
**Vulnerability:** External client wrappers around `expo-secure-store` failed to return promises for `setItemAsync` and `deleteItemAsync`.
**Learning:** Omitting return statements in adapter methods creates "floating promises". The parent client (Supabase Auth) assumes instantaneous success and ignores potential keystore failures. This silent failure can lead to insecure, inconsistent session states or unexpected token loss.
**Prevention:** Always explicitly `return` the Promises generated by asynchronous storage mechanisms when bridging them into third-party clients or state managers.
